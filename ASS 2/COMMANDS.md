# ASS 2 – Java CORBA Reverse String: Execution Commands

## ⚠️ IMPORTANT NOTE
CORBA support (`orbd`, `idlj`) was **removed in Java 11+**.
This assignment requires **Java 8 or Java 10** to run.

---

## Prerequisites
- Java 8 / Java 10 JDK (with `idlj` and `orbd` tools)
- Files: `ReverseModule.idl`, `ReverseServer.java`, `ReverseImpl.java`, `ReverseClient.java`

---

## Step-by-Step Execution (3 Terminals Required)

### Terminal 1 – Compile & Start ORB Daemon
```bash
# Step 1: Verify Java version (must be < 11)
java -version

# Step 2: Generate Java stubs from IDL file
idlj -fall ReverseModule.idl

# Step 3: Compile all Java files (one warning is expected)
javac *.java ReverseModule\*.java

# Step 4: Start the CORBA Object Request Broker Daemon
orbd -ORBInitialPort 1050
# Keep this terminal running
```

### Terminal 2 – Start the CORBA Server
```bash
java ReverseServer -ORBInitialPort 1050 -ORBInitialHost localhost
```
**Expected output:** `ReverseServer started...`

### Terminal 3 – Run the Client
```bash
java ReverseClient -ORBInitialPort 1050 -ORBInitialHost localhost
```
**Enter when prompted:**
- A string to reverse, e.g., `hello`

**Expected output:**
```
Enter a string to reverse: hello
Reversed string: olleh
```

---

## Files Generated by idlj
After running `idlj -fall ReverseModule.idl`, the `ReverseModule/` directory will contain:
- `Reverse.java` — Interface
- `ReverseHelper.java` — Helper utility class
- `ReverseHolder.java` — Holder class
- `ReverseOperations.java` — Operations interface
- `ReversePOA.java` — Portable Object Adapter (server skeleton)
- `_ReverseStub.java` — Client stub

---

## Shutdown
- `Ctrl+C` in Terminal 1 (orbd) and Terminal 2 (server)
