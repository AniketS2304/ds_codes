# ASS 2 – Java CORBA Reverse String: Execution Commands

---

## ✅ Check If It Will Work on Your College PC

Run this **first** in the terminal:
```bash
java -version
```
- If output shows `java version "1.8.x"` → **Will work ✅**
- If output shows `17`, `21`, or anything `11+` → **Won't work ❌** (CORBA removed)

Also check if `idlj` exists:
```bash
idlj
```
- If it shows usage/help → **Will work ✅**
- If "not recognized" error → **Won't work ❌**

---

## Prerequisites
- **Java 8 JDK** (must be < Java 11)
- Files in same folder: `ReverseModule.idl`, `ReverseServer.java`, `ReverseImpl.java`, `ReverseClient.java`

---

## Step-by-Step Execution (3 Terminals Required)

### Terminal 1 – Compile & Start ORB Daemon

```bash
# Step 1: Verify Java version (must be 1.8.x)
java -version

# Step 2: Generate Java stubs from IDL file
idlj -fall ReverseModule.idl

# Step 3: Compile all Java files (one warning about unchecked is expected - ignore it)
javac *.java ReverseModule\*.java

# Step 4: Start the CORBA Object Request Broker Daemon on port 1050
orbd -ORBInitialPort 1050
```
> ⚠️ Keep Terminal 1 running. Do NOT close it.

---

### Terminal 2 – Start the CORBA Server

Open a **new terminal** in the same directory:
```bash
java ReverseServer -ORBInitialPort 1050 -ORBInitialHost localhost
```
**Expected output:**
```
ReverseServer started...
```
> ⚠️ Keep Terminal 2 running.

---

### Terminal 3 – Run the Client

Open another **new terminal** in the same directory:
```bash
java ReverseClient -ORBInitialPort 1050 -ORBInitialHost localhost
```
**Enter when prompted:**
- A string to reverse, e.g., `hello`

**Expected output:**
```
Enter a string to reverse: hello
Reversed string: olleh
```

| File | Purpose |
|------|---------|
| `Reverse.java` | Interface |
| `ReverseHelper.java` | Utility for type casting |
| `ReverseHolder.java` | For inout/out parameters |
| `ReverseOperations.java` | Operations interface |
| `ReversePOA.java` | Server skeleton |
| `_ReverseStub.java` | Client stub/proxy |

---

## Common Errors & Fixes

| Error | Fix |
|-------|-----|
| `idlj: not found` | Java version is 11+, need Java 8 |
| `orbd: not found` | Java version is 11+, need Java 8 |
| `org.omg.CORBA.COMM_FAILURE` | orbd not running yet — start Terminal 1 first |
| `org.omg.CosNaming.NamingContextPackage.NotFound` | Server not started — start Terminal 2 first |
| Warning: `unchecked or unsafe operations` | Normal — ignore this warning |

---

## Shutdown
- Press `Ctrl+C` in Terminal 1 (orbd) and Terminal 2 (server) after client finishes.
